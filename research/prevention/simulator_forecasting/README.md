# TimesFM trajectory forecasting

This package applies TimesFM 3 zero-shot to time series generated by the GGG simulator. It supports two experiments:

1. Forecastability of simulator trajectories against transparent baselines.
2. Scenario preference ranking under GGG alignment objectives applied to TimesFM forecast distributions.

## Targets

The primary channels are simulator outputs: domain apertures, domain SI values, Lyapunov quantities, and ecological displacement components. Forecasts preserve dimensionless simulator steps.

## Forecastability

The forecastability runner evaluates seven scenarios with rolling origins, a 40-step context, and a 10-step horizon. At each origin, only the prefix is supplied to the forecasting function. The continuation generated by the simulator is held out for scoring.

The comparison includes last-value, drift, linear-trend, and zero-shot TimesFM forecasts. Metrics are reported per scenario and channel.

## Scenario preference ranking

The ranking experiment asks a harder question. At shared forecast origins, TimesFM forecasts the continuation of each scenario. Those forecasts are scored with GGG-native objectives:

- high Superintelligence Index level and progress;
- aperture proximity to A*;
- Lyapunov relief;
- low and declining displacement;
- narrow percentile bands;
- smooth SI continuation.

Scenarios are ranked by the resulting preference score inside each origin-horizon cell. The same score is computed on the actual simulator continuation, so the TimesFM ranking can be compared with the simulator's own continuation ranking. Stability is reported across origins and horizons.

## Run

Generate the seven simulator trajectories if they are absent:

```powershell
python research/prevention/simulator/run_scenarios.py
```

Install the optional TimesFM dependency:

```powershell
pip install "timesfm[torch]>=3.0.2"
```

Run forecastability:

```powershell
python -m research.prevention.simulator_forecasting.run_forecasts forecast --model timesfm
```

Run scenario preference ranking:

```powershell
python -m research.prevention.simulator_forecasting.run_forecasts rank --rank-model timesfm --require-timesfm
```

The package uses `google/timesfm-3.0-pytorch` with frozen weights under `timesfm-non-commercial-license-v1.0`.

## Results

### Forecastability

Across 105 scenario-channel combinations, TimesFM had the lowest mean absolute error in 80 combinations, drift in 23, and last-value persistence in 2. The 10% to 90% bands covered 90.5% of held-out values overall.

### Scenario preference ranking

Across origins `{40, 50, 60, 70}` and horizons `{5, 10, 20}`, TimesFM's mean preference ranking placed `uniform_weights` and `asymmetric` at the top, followed by `at_astar` and `strong_coupling`. `canonical` ranked lower, and `weak_coupling` ranked last. The actual simulator continuations produced a closely related order. Mean Spearman agreement between forecast ranks and actual ranks was 0.74.

The ranking therefore converts TimesFM forecasts into a GGG preference profile over simulated governance regimes.
